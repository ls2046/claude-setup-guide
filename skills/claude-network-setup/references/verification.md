# 网络与环境验收

## 检测分层

在用户实际使用的设备和浏览器打开 [Net.Coffee Claude](https://ip.net.coffee/claude/)；用户要求 Claude Code 专项时再看 [对应检测页](https://ip.net.coffee/claude/claudecode.html)。结合独立检查和核心连接记录，不只看首页分数。不自动登录账号或发送付费请求；页面的必要无认证探测与真实账号测试分别记录。

| 层 | 检查与判读 |
| --- | --- |
| 流量接管 | 活动客户端、系统代理、TUN、模式、绕过名单、应用环境变量、手机按应用 VPN；TUN 开启不等于所有规则都代理 |
| 实际出口 | 终端显式代理、浏览器 HTTP 回显、目标域名连接命中和完整链路交叉检查；入口地址不一定是出口 |
| DNS | 实际浏览器运行 [DNS 测试](https://browserleaks.com/dns)，查看系统 DNS、核心上游、DoH/DoT、浏览器安全 DNS及 Android 私人 DNS；不能仅以解析器和出口国家不同判泄露 |
| WebRTC | 实际浏览器运行 [WebRTC 测试](https://browserleaks.com/webrtc)，比较真实 ICE 公网候选和 HTTP 出口；无需摄像头/麦克风授权；mDNS `.local`、私有地址不是公网泄露证据 |
| IPv6 | 检查原生 IPv6、IPv6 请求和 ICE 候选及命中；无法承载预期 IPv6 时按授权范围限制，而不是只测 IPv4后宣布无泄露 |
| 环境 | 系统时间准确、时区读回、浏览器实际 Intl 时区/语言、应用语言偏好；商店国家和付款资料另行核对 |
| 可用性 | DNS/TCP/TLS/HTTP、前端依赖、登录/业务 API、持续流逐层验证；各层通过不能代替下一层 |

Net.Coffee 的“中国出口 IPv4”显示本地地址可能来自按规则直连的探测端点，并不能单凭该卡片认定 Claude 直连。查看对应请求和命中规则：若用户期望分流则解释；若要求全外网统一出口，就验证并覆盖该范围，不只把检测域名单独送代理。

远端 DNS 提供商的 IPv6 解析器不是本机 IPv6 出口证据。Chrome/Edge 与手机默认浏览器可不同；检测未完成、被阻止、无公网候选和真正无泄露分开描述。GeoIP 数据库对国家/城市判断冲突时记录来源差异，不按一个图标反复改路由或时区。

系统时钟应保持准确同步。设置固定时区时调整自动时区，不默认关闭自动日期时间；如果自动时区已关闭却还变化，检查明确相关的切换器、启动项、计划任务和 MDM，停止已授权的具体写入者。不要用错误系统时间伪装地区。

## 慢与不稳定的区别

先短测再长测，不让诊断耗尽链路。候选相同目标交替、串行测，避免并发下载互相抢带宽。先每路 3–5 次短请求；用户要求稳定性时可做 5–10 分钟低频采样，先报初步结果，再报告完整窗口。保留失败样本，报告成功率、超时、成功样本中位数/p95、首响应和完整下载速度。

- 以用户的实际速度目标为准，优先低超时和稳定性，不必追求峰值；Mbps 与 MB/s 相差 8 倍。
- 平均速度可接受但频繁长尾/超时，仍会表现为卡顿。
- `curl` 连接本地代理的 connect 时间不等于远端握手；TTFB 也不是网页完整加载或模型首 token 时间。
- 使用有限大小的已知公开文件，核对 HTTP 状态和实际字节数。Range 可能被忽略，应设置时间/体积上限并检查响应；部分下载不能当作完整成功。
- 不指定代理或 `--noproxy '*'` 只能绕过应用显式代理；TUN 仍可能接管，因此不能把它命名为“物理直连”。真正直连需要独立验证路由，不为基线擅自关闭正在使用的网络。

## 内置短请求探针

```bash
python3 scripts/probe_routes.py   --route old=http://127.0.0.1:17891   --route candidate=http://127.0.0.1:17892   --url https://www.google.com/generate_204   --rounds 5 --interval 1 --output /tmp/network-probe.json
```

端口仅为示例，先创建并验证隔离的核心监听，不要直接照抄历史端口。只允许无凭据的本地代理地址；凭据在核心私密配置内。探针禁用默认 curl 配置，按路由轮流测，无重试/无重定向以便保留失败，结果不含响应正文。2xx 只代表该无认证端点成功；3xx/401/403 可证明某些传输层连通，不能证明业务成功。工具的 `remote_ip` 常是代理地址，不当作出口 IP。

不做重启/休眠/故障演练就标未测，不通过实际断网来给普通测速附加“完整验收”。
