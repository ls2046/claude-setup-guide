# 邮箱、注册与登录

## 准备

优先复用用户自己掌握的邮箱。教程偏好 Gmail，也可使用 Proton；没有 Gmail 时可在手机创建 Google 账号，再开通 Gmail。若创建 Google 账号时已有 Gmail 地址，不重复创建。检查能收信并提示妥善保存恢复方式，不索取邮箱密码或恢复码。

普通独立浏览器配置文件便于隔离账号；不把指纹浏览器、买老号、清空所有 Cookie、固定养号天数设为前置条件。Gmail 老号更稳定没有从本教程得到证实；标准 Google 登录信息不提供账号创建时间，但不能据此断言平台不可能有其他风险信号。

## 直接操作

1. 网络尚不稳定先修网络；已可用则打开官方 Claude 页面，不重复测速阻塞注册。
2. 按用户已有登录方式与当前 UI 选择邮箱或 Google 登录，核对目标账号，避免误进另一个 Google 会话。
3. 邮箱流程关注收信地址、垃圾箱及当前有效邮件；同设备链接与跨设备验证码回填以页面为准，验证码由用户在官方页面输入。
4. 注册或登录后核对账号和套餐；用户需要可用性验证时做最小聊天测试。看到 KYC 转身份验证分支，不继续批量注册重试。

## 常见卡点

- 收不到邮件：判断请求有没有发出、是否限流、邮箱是否正确；按页面重发间隔处理，不连续刷请求。
- 链接过期/在另一设备打开：回到原发起会话，用当前有效邮件按提示完成。不要读取或输出其他邮件。
- 页面白屏/重定向循环：查看实际网络错误、站点权限与扩展，先小范围处理；保留已有登录和未发送内容。
- 通行密钥弹窗卡死：先正常取消，必要时让用户完成本机验证；仅在授权和保存未提交内容后重启相关应用。
- 忘记邮箱或账号混淆：从当前页面、已授权收据和登录记录定位，不收集无关账户。

## 来源与经验

- [Claude 登录说明](https://support.claude.com/en/articles/13189465-log-in-to-your-claude-account)：核对当下登录和跨设备流程。
- [Google 登录字段](https://developers.google.com/identity/openid-connect/reference)：区分凭证签发时间与账号年龄。
- [Proton 人机验证](https://proton.me/support/human-verification)：不能保证仅输入账号密码就能注册。

教程中的“手机注册三个 Gmail 顺利”“七次 Claude 注册只有一次 KYC”属于个人样本，不是免验证承诺。需要替用户创建邮箱时按当前工具对密码、验证码、条款的要求执行，不绕过安全验证。
