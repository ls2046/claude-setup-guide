# KYC、账号限制与支持

## 识别提示，不混淆原因

区分邮箱验证码、短信验证、Google/Apple 登录验证、银行卡验证、年龄核验、Claude 身份 KYC 和账号停用。先读取官方页面及提示，不把每种验证都归因于 IP。保留错误类别和发生阶段，避免采集证件图、生日、号码等不必要数据。

教程的顺序是注册后订阅，再处理订阅后遇到的 KYC；这是作者经历。当前用户在哪一步被要求验证，就在哪一步处理，不强迫先付款来触发验证，也不保证所有人只会订阅后遇到。

## 本人验证

1. 核对页面来自 Claude 官方流程及其当前验证服务，检查目标账号、验证是否已提交、是否仍在审核。
2. 查看当下支持的国家和本人证件类型。护照、驾照等是否可用以实际流程为准；不要求用户必须同时拥有护照和驾照。
3. 指导用户用有效原件完成拍摄，检查清晰度、完整边角、反光、证件有效期及摄像头权限。证件和活体自拍由用户本人在验证页完成，不发送到聊天或第三方代办。
4. 若镜像无法调用相机或完成面容验证，保留入口，请用户在手机本机完成，随后恢复镜像并读回结果。
5. 如果失败，先读取原因：图像/过期/不支持/技术错误/审核拒绝分开处理。已提交审核则查状态，不盲目反复提交。
6. 没有页面支持的本人证件时，检查其他官方验证选项或联系支持。可以帮助导航、翻译和整理问题，不借用他人证件、找人代脸、购买验证账号或伪造资料。

## 账号停用与申诉

- 用户想恢复账号：打开当前官方申诉入口，用对应账号登录，核对停用通知；整理账号、发生时间、错误和已尝试动作，写简洁事实申诉。若 UI 要求登录而无法进入，按官方帮助中心提供的支持方式继续。
- 用户想退款：转退款参考；不要以必须先解封为条件拖延用户明确要做的退款/取消。
- 两个诉求都有：解封与订单退款分别准备、分别追踪。不得编造账号用途、从未使用等事实，也不要为恢复访问继续注册替代账号规避停用。
- 请求发给官方支持前，确保用户已授权该沟通对象与目的；只写文案不等于授权发送。记录提交回执而不是只记录按钮已点。
- 验证通过后核对原账号权益与授权的实际使用；申诉受理并不代表恢复。
