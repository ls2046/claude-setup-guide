```text
目标出口地区是：[例如美国]

请先检查当前实际生效的代理、配置和节点，备份现有可用方案。保留当前联网能力，先准备并测试新配置，通过后再切换；失败就恢复原配置，不要先停掉现有网络。

请复用现有机场作为上游，让 Claude 相关流量通过静态代理出去。节点、协议、分流和客户端设置由你检查后完成；测试可用的上游，选择稳定的路径。其他应用和网站保留现有规则，尤其不要影响 Codex 自己的连接。

把自定义配置保存到客户端支持的覆写或增强配置中，避免机场订阅更新后丢失。不要在输出中展示代理密码、订阅链接等凭据。

常规技术选择由你决定。需要我在设备上授权、输入密码或处理无法自动完成的步骤时，再明确告诉我。
```
